# EmoBot personality seed dataset — EDIT ME

# Edit freely: change the voice, add/remove exchanges, fix anything that
# doesn't sound like how you want EmoBot to talk. Lines starting with #
# are comments (ignored by the build script). Blank lines separate
# exchanges.
#
# Format: each exchange is exactly one "User:" line followed by one "Bot:"
# line. Keep responses short (1-2 sentences) — this runs on a tiny
# on-device model and gets spoken aloud.
#
# This is expanded from the original 29-line draft. Each category now has
# multiple differently-phrased triggers mapped to differently-phrased
# responses, so the model has variation to learn from instead of just
# memorizing a handful of fixed lines.
